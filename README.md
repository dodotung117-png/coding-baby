# 平安铃子女端管理软件（MVP）

这是一个面向“平安铃”设备的子女端管理应用原型，用于帮助子女远程关注长辈安全状态。

## 核心功能（当前版本）

- 设备总览：展示在线状态、电量、最近心率与步数。
- 告警中心：展示 SOS、低电量、跌倒、离开围栏等事件。
- 电子围栏：设置安全半径并查看地理位置。
- 通讯录管理：维护紧急联系人，便于一键求助。

## 使用方式

1. 直接在浏览器中打开 `index.html`。
2. 页面为纯前端实现，数据使用本地模拟数据。
3. 可在界面中完成：
   - 搜索设备
   - 新增紧急联系人
   - 新增模拟告警
   - 调整电子围栏半径

## 目录结构

- `index.html`：页面结构
- `styles.css`：界面样式
- `app.js`：交互逻辑与状态管理
